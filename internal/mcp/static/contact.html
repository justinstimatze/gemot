Contact

Gemot is operated by Schorl Dynamics LLC.

Support & general inquiries

Email justin@gemot.dev for account issues, refund requests, API key problems, or general questions about the service. We respond to privacy and data-rights requests within 30 days as described in the Privacy Policy.

Bugs & feature requests

Gemot is open source. File an issue or open a pull request on GitHub — that is the fastest way to reach the people who maintain the code.

Abuse & content policy reports

To report content that violates the Content Policy, email justin@gemot.dev with the deliberation ID and a description of the concern, or use the admin action:report_abuse tool directly from an MCP or A2A client.

Security reports

If you believe you've found a security vulnerability, see SECURITY.md for the disclosure process.
